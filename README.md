# apcupspi

Turn a Raspberry Pi 4/5 into an emulated **APC Network Management Card 2
(AP9631)** for a UPS: an HTTPS web interface, SNMP (PowerNet-MIB) agent and
NUT (Network UPS Tools) backend — so any UPS monitored by the Pi presents
itself to the network exactly like a real APC NMC.

## What you get

- **Web UI** on :443 (`:80` redirects) emulating the NMC2 interface —
  status, logs, control, tests and configuration — backed live by NUT
- **SNMP** on :161 serving the APC PowerNet-MIB subtree via a
  `pass_persist` agent (`apc-nmc-agent.py`) — works with NMS tools that
  expect a real APC card (v1/v2c + v3 read-only user)
- **NUT standalone**: `upsd` (port 3493) + `upsmon` shutdown controller +
  `apc_modbus` driver (binary included — Debian's `nut` package doesn't ship it)
- **Resilience**: kernel watchdog + `RuntimeWatchdogSec`, panic-reboot
  sysctl, OOM tuning, `net-watchdog` connectivity-recovery timer
- **Utilities**: `pi-system-backup.sh` builds a flashable full-system `.img`
  (with `--clean` mode producing a publishable image with secrets stripped
  and a first-boot setup wizard enabled)

## Install

On a fresh Raspberry Pi OS (64-bit) image — Raspberry Pi Imager
customisation (hostname, user, SSH key) is honoured — run:

```bash
git clone https://github.com/ArMaTeC/apcupspi.git
cd apcupspi
sudo ./install.sh
```

or standalone (downloads the repo tarball itself):

```bash
curl -fsSL https://raw.githubusercontent.com/ArMaTeC/apcupspi/main/install.sh | sudo bash
```

The installer deploys all files and services, then offers an interactive
wizard that collects: hostname, root password, SSH public key, network
(DHCP or static), web-interface credentials, UPS name/driver/port,
NUT passwords, SNMP communities and device info — and can regenerate the
HTTPS certificate.

Re-run the wizard anytime with `sudo firstboot-wizard.sh`.

## Hardware notes

- Tested on Pi 4; Pi 5 supported (config.txt uses per-model sections)
- Optional install-time choices: onboard WiFi/BT disable, Pi 4 mild
  overclock, 10G `/var/swap`, Argon One case fan daemon
- UPS connection: USB or serial depending on the NUT driver you pick
  (`apc_modbus` default; `usbhid-ups`, `apcsmart`, `blazer_usb` etc. work)

## Layout

The repo mirrors filesystem layout — files land exactly where they sit:

```
install.sh                  installer (payload = this repo)
usr/local/bin/              apc-nmc-web.py, apc-nmc-agent.py, web assets
usr/local/sbin/             firstboot-wizard.sh, pi-system-backup.sh, net-watchdog.sh
usr/lib/nut/apc_modbus      locally-built NUT driver (arm64)
usr/local/lib/              libmodbus.so.5 (runtime dep of apc_modbus)
etc/nut/                    NUT config templates (secrets are generated, not shipped)
etc/apc-nmc/                nmc.conf.default template + public CA material
etc/snmp/                   (snmpd.conf is generated by install.sh)
etc/systemd/system/         units, timers, hardening/OOM drop-ins
etc/sysctl.d/               panic-reboot + OOM tuning
etc/argon/                  optional Argon One fan/button daemon
```

## Backup / imaging

```bash
sudo pi-system-backup.sh           # full clone image -> /root/pi4-backup-*.img.gz
sudo pi-system-backup.sh --clean   # publishable image: secrets stripped,
                                   # first-boot wizard enabled
```

Flash either image to a new SSD/SD and boot — the clean image runs the
setup wizard on first console login.
