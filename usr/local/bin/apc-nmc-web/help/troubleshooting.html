UPS داده نمی‌دهد / «آخرین داده معتبر»

  • سرویس NUT را چک کنید: systemctl status nut-server و systemctl status apc-nmc-upsdrv.
  • کابل/پورت Modbus یا USB UPS را بررسی کنید؛ upsc myups باید متغیرها را برگرداند.
  • اگر UPS جدید است، نام آن در [ups] name در nmc.conf باید با ups.conf یکی باشد.

ریست‌های خودکار مکرر

واچ‌داگ شبکه (net-watchdog) وقتی دروازه و اینترنت هر دو ناپایدار باشند دستگاه را ریست می‌کند. اگر ریست‌های عجیب دارید Event Log را ببینید و اتصال شبکه را چک کنید — حداکثر ۳ ریست در هر قطعی پیوسته انجام می‌شود.

به UI نمی‌رسم

  • اگر روی WiFi بودید و رادیو را غیرفعال کرده‌اید، از Ethernet وصل شوید و در System › WiFi Setup › Wireless Hardware دوباره Enable و Reboot کنید.
  • پورت 443/80 را در فایروال چک کنید.
  • systemctl status apc-nmc-web و journal آن را ببینید.

به‌روزرسانی ناموفق

  • در About › System کنسول زنده لاگ خطا را نشان می‌دهد؛ معمولاً مشکل شبکه/گیت‌هاب یا sha256 است.
  • با «Rollback» به نسخه قبلی برگردید؛ بکاپ‌ها در /var/backups/apc-nmc/ نگهداری می‌شوند.

اعلان‌ها نمی‌رسند

  • از دکمه Test هر کانال استفاده کنید؛ خطای دقیق در Event Log ثبت می‌شود.
  • برای SMTP پورت/TLS و احراز هویت را چک کنید؛ برای webhook URL و کد پاسخ سرور را.
  • سطح حداقل (Minimum Severity) را پایین‌تر بیاورید — شاید رویداد فیلتر شده باشد.

Modbus/MQTT کار نمی‌کند

  • Modbus: سرویس را در System › Services فعال کنید و پورت را در فایروال باز کنید؛ Unit ID کلاینت را چک کنید.
  • MQTT: با «Save & Test» اتصال را آزمایش کنید؛ خطای اتصال/TLS/احراز در همان کارت و Event Log دیده می‌شود.

دیباگ بیشتر

از About › System دکمه «Download Support Bundle» یک فایل tar.gz با کانفیگ پاک‌سازی‌شده + journal + وضعیت سرویس‌ها می‌دهد — برای گزارش مشکل به توسعه‌دهنده ایده‌آل است.
