This is the UPS Network Management PI — a Network Management Card (NMC) running on a Raspberry Pi that monitors and controls a UPS through the NUT server. This guide explains how to use the interface; installation and first-time setup are covered in the GitHub README.

Page Layout

  • Top bar: brand mark, live-data dot (green = receiving UPS data), the alarm status pill (click it to jump to UPS Status), server clock, light/dark theme button, and your user name with role.
  • On-battery banner: while the UPS is on battery (OB), a warning banner on every page shows charge and estimated minutes remaining.
  • Update banner: when a new software release exists, a yellow bar appears at the top; click it to open the update page.
  • Side menu: the main sections. Sub-items expand below each section. On mobile the menu collapses into a top bar.
  • Breadcrumb: shows your current location at the top of each page.

Full detail in User Roles.

Live Data

Dashboard tiles, the top-bar pill and the status table refresh every few seconds from /status.json without reloading the page. The green dot beside the clock means data is live; if it goes dark the UPS link is down.
