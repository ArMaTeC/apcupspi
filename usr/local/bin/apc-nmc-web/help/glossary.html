NUT Status Codes (ups.status)

CodeMeaning
OLOnline — on mains power, normal state
OBOn Battery — mains is out, running on battery
LBLow Battery — remaining runtime reached the low threshold
RBReplace Battery — the UPS says the battery needs replacing
HBHigh Battery — battery charged above its safe limit
CHRGCharging — battery is charging
DISCHRGDischarging — battery is draining
BYPASSLoad fed via the bypass path, not the inverter
CALRuntime calibration in progress
TESTSelf-test in progress
OVEROverload — draw exceeds UPS capacity
TRIM / BOOSTAVR is stepping the voltage down/up
OFFUPS is off/offline
FSDForced Shutdown — an emergency shutdown is armed
ALARMAn internal UPS alarm is active

Codes combine with spaces, e.g. OL CHRG or OB DISCHRG LB.

Terms

TermMeaning
RuntimeHow long the UPS can run the current load on battery
TransferSwitching between mains and battery (or bypass)
VA vs WApparent power vs. real power; UPS ratings are usually in VA
AVRAutomatic Voltage Regulation — corrects low/high mains without using the battery
NUTNetwork UPS Tools — the Linux daemon that talks to the UPS
NMCNetwork Management Card — what this device emulates
BMSBuilding Management System (Modbus/BACnet consumer)
PCNSPowerChute Network Shutdown — APC software that safely powers off servers
EAPoL / 802.1XPort-based authentication on managed Ethernet switches
EPOEmergency Power Off — immediate output cut
