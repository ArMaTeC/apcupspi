Besides the web UI, the card exposes several machine interfaces for monitoring and automation.

REST API (JSON)

EndpointPurpose
GET /status.jsonFull UPS state as JSON (the same data the UI polls). ?frag=1 returns only the live dashboard fragments
GET /datalog.json[?hours=N&off=O&lim=L]Data-log samples — hours limits the window, off/lim paginate newest-first
GET /events.txt /data.txtRaw text logs; data.txt?csv=1&hours=N for CSV
GET /api/v1/varsAll NUT variables (Bearer token required)
POST /api/v1/commandsSend a UPS instant command (Bearer token required)
GET /metricsPrometheus-format metrics

The Bearer token is generated on About › Update Settings (admin) and sent as Authorization: Bearer <token>.

SNMP (APC PowerNet)

The apc-nmc-snmpd agent implements the APC PowerNet MIB (.1.3.6.1.4.1.318): UPS state, battery, input/output readings and traps to an NMS. Supports v1/v2c communities and a read-only v3 user — existing APC-aware monitoring tools work unmodified.

Modbus TCP

For BMS/SCADA systems: UPS registers are served on port 502 (configurable) — discrete inputs for status flags, input registers for readings, an optional command register. Full map in docs/modbus-registers.md.

MQTT

Publishes the UPS state as JSON to <prefix>/state every configured interval — for Home Assistant, Node-RED and BMS platforms. Configure under Network Services and use the test-publish button to verify connectivity.

Syslog / Webhook

Events are also pushed to syslog (UDP/TCP/TLS) and as JSON webhook POSTs — configured on the Notifications card.
