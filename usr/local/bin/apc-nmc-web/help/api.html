علاوه بر وب‌UI، کارت چند رابط برنامه‌نویسی برای مانیتورینگ/اتوماسیون دارد.

REST API (JSON)

Endpointتوضیح
GET /status.jsonوضعیت کامل UPS به‌صورت JSON (همانی که UI استفاده می‌کند). ?frag=1 فقط فرگمنت‌های داشبورد می‌دهد
GET /datalog.json[?hours=N&off=O&lim=L]نمونه‌های دیتالاگ؛ hours بازه زمانی، off/lim صفحه‌بندی
GET /events.txt /data.txtخروجی متنی لاگ‌ها؛ data.txt?csv=1&hours=N برای CSV
GET /api/v1/varsهمه متغیرهای NUT (نیازمند Bearer token)
POST /api/v1/commandsارسال فرمان به UPS (نیازمند Bearer token)
GET /metricsمتریک‌های Prometheus

توکن Bearer از About › Update Settings (ادمین) ساخته می‌شود و در هدر Authorization: Bearer <tok> فرستاده می‌شود.

SNMP (APC PowerNet)

سرویس apc-nmc-snmpd MIB پاورنت APC را پیاده می‌کند: وضعیت UPS، باتری، ورودی/خروجی و ارسال Trap به NMS. از v1/v2c (community) و v3 (USM) پشتیبانی می‌شود. OIDهای پایه همان .1.3.6.1.4.1.318 APC است.

Modbus TCP

برای سیستم‌های BMS/SCADA: رجیسترهای UPS روی پورت 502 (قابل تنظیم) سرو می‌شوند. نقشه کامل رجیسترها در docs/modbus-registers.md. گزینه Write اجازه اجرای فرمان از طریق رجیستر کنترل می‌دهد.

MQTT

هر N ثانیه وضعیت UPS به‌صورت JSON روی <prefix>/state منتشر می‌شود — برای Home Assistant، Node-RED، BMS. در Network Services فعال و با Test آزمایش کنید.

Syslog / Webhook

رویدادها هم‌زمان به syslog (UDP/TCP/TLS) و webhook JSON هم فرستاده می‌شوند — پیکربندی در Notifications.
