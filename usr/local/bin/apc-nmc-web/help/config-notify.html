The Notifications card on the Configuration page controls which channels fire when UPS events occur. All enabled channels work in parallel and each has its own test button.

Minimum Severity

Only events at or above this level are sent out; lower ones are only written to the Event Log. Choices: Info, Warning, Critical.

Alert Routing Matrix

The table at the bottom maps each trigger type (power, battery, communication, system) to the channels that should fire for it. A fully unchecked row alerts nowhere for that trigger.

Testing

Each channel's Test button sends a sample event using the saved configuration — Apply changes first. Delivery failures are written to the Event Log as warnings.

Notes

  • SMTP password and webhook URLs are secrets — the form shows a "configured" flag; leave a field blank to keep the stored value.
  • For TLS channels keep the clock correct (NTP) or certificate validation fails.
