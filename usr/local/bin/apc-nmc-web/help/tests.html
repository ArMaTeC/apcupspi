Tests › Diagnostics runs UPS tests and manages automatic schedules.

Self-Test

  • Initiate UPS Self Test: the UPS briefly runs on battery to check battery health. The result appears in ups.test.result and the Event Log.
  • Status may briefly show TEST or CAL while it runs.
  • A failed test usually means the battery needs replacing (RB).

Runtime Calibration

  • The UPS discharges the battery down to the low-battery threshold so its runtime estimate becomes accurate.
  • Warning: calibration deeply discharges the battery and keeps the load on battery for a while — only run it when an outage risk is acceptable. The page shows the prerequisites (battery ~100%, steady load ~30%) and the UPS silently ignores the command until they are met.
  • Stop Calibration aborts a running calibration.

Scheduling Card

FieldMeaning
Weekly Self-TestDay and hour for an automatic weekly self-test. Empty day = disabled.
WhenDay and hour for a scheduled UPS power-off (once per week)
After Power-OffReturn when power is restored vs. Stay off until manually restarted

Schedules run in server local time; every execution is recorded in the Event Log. Clear the day to disable a schedule.

Notes

  • Running tests requires the Administrator or Device role.
  • The latest test result also appears on UPS Status.
