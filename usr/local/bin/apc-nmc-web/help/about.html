صفحه About › System شناسنامه نرم‌افزار و ابزار به‌روزرسانی است.

جدول اطلاعات

  • Product: UPS Network Management PI — نام محصول.
  • Version: نسخه نصب‌شده از /etc/apc-nmc/version خوانده می‌شود.
  • App URL / User / Date: آدرس دسترسی، کاربر جاری و زمان رندر صفحه.

به‌روزرسانی نرم‌افزار (admin)

  • Check for Updates: از مخزن گیت‌هاب آخرین ریلیز را می‌خواند و در صورت وجود نسخه جدیدتر، بنر «Software update available» در همه صفحه‌ها ظاهر می‌شود.
  • Apply Update: دانلود + بررسی sha256 + نصب بسته. فرایند در کنسول زنده (Live Log) داخل همان صفحه دیده می‌شود.
  • Rollback: بازگرداندن بکاپ گرفته‌شده قبل از آخرین به‌روزرسانی.
  • هنگام به‌روزرسانی، فایل‌های پیش‌فرض جدید با حفظ مقادیر فعلی به nmc.conf اضافه می‌شوند (merge پیش‌فرض‌ها).

API Token (admin)

توکن Bearer برای REST API. «Copy» آن را کپی می‌کند، «Generate» توکن جدید می‌سازد (توکن قبلی باطل می‌شود) و «Clear» API را غیرفعال می‌کند. توکن را به کسی جز ادمین ندهید.

Support Bundle

دکمه «Download Support Bundle» فایل support.tgz می‌سازد: نسخه، کانفیگ پاک‌سازی‌شده (بدون رمزها)، رویدادها، وضعیت سرویس‌ها و journal. برای گزارش باگ به توسعه‌دهنده ضمیمه کنید.
