About › System is the software identity card and update centre.

Identity Table

  • Product: UPS Network Management PI.
  • Version: installed release, read from /etc/apc-nmc/version.
  • App URL / User / Date: access URL, your login and page render time.

Software Updates (admin)

  • Check for Updates: queries the GitHub repository for the newest release; if one exists a yellow banner appears on every page.
  • Apply Update: downloads the payload, verifies sha256, deploys files, rebuilds the UPS driver and restarts services — progress streams into the live console on the page.
  • Rollback: restores the per-file backup taken before the last update.
  • Releases: the link beside "Latest Version" opens the GitHub releases page (full notes and history).
  • Updates merge new default settings into nmc.conf without overwriting your existing values.

Card Actions (admin)

  • Restart Interface: restarts only the web UI — a few seconds of unavailability, sessions survive.
  • Reboot Card: reboots the whole Pi — everything (including this interface) stops until it comes back, roughly a minute.

API Token (admin)

Bearer token for the REST API. Copy puts it on the clipboard, Generate makes a new one (the old stops working), Clear disables API access. Treat it like a password — admin only.

Support Bundle

Download Support Bundle builds support.tgz: version, sanitized config (secrets stripped), events, service states, failed units, recent journals and network info — attach it to bug reports.
