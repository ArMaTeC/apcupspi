این صفحه به بخش‌های امنیتی و نگهداشت داده مربوط است: تغییر رمز، نشست‌ها، پشتیبان‌گیری و توکن API.

تغییر رمز عبور

  • در کارت Change Password رمز فعلی و رمز جدید را وارد کنید. این کار فقط رمز خودتان را عوض می‌کند — حتی ادمین هم از همین‌جا رمز خودش را عوض می‌کند.
  • کاربرانی که فقط از RADIUS احراز می‌شوند حساب محلی ندارند؛ پیام «managed by the authentication server» می‌گیرند.
  • رمز جدید به‌صورت هش (PBKDF2) در nmc.conf ذخیره می‌شود.

نشست‌های فعال (Sessions)

فهرست نشست‌های باز (کاربر، IP، آخرین فعالیت) را نشان می‌دهد. Administrator می‌تواند هر نشست را با «Log off» خاتمه دهد — مثلاً وقتی دستگاهی گم شده.

Backup / Restore

  • Download Backup: فایل .bak شامل تنظیمات فعلی nmc.conf را دانلود می‌کند (ادمین).
  • Restore: فایل پشتیبان را بازگردانی می‌کند. قبل از جایگزینی، از فایل فعلی خودکار نسخه پشتیبان تهیه می‌شود. رازها (پسوردها/توکن‌ها) در بکاپ هستند — فایل را امن نگه دارید.
  • Restore فایل‌های نامعتبر یا خیلی بزرگ را رد می‌کند.

توکن API

در کارت Update Settings صفحه About، توکن Bearer برای استفاده از REST API (/api/v1/…) نمایش داده می‌شود. دکمه «Copy» آن را به کلیپ‌بورد می‌برد. این توکن دسترسی کامل می‌دهد — فقط Administrator می‌بیند. با Generate توکن جدید بسازید و با Clear آن را غیرفعال کنید.

قفل حساب (Lockout)

چند تلاش ناموفق پیاپی برای ورود، IP را برای مدت کوتاه قفل می‌کند تا حمله brute-force کند شود. رویداد ورودهای ناموفق در Event Log ثبت می‌شود.

کوکی نشست

کوکی nmc_session با پرچم‌های HttpOnly + Secure + SameSite=Lax ساخته می‌شود و با CSRF token محافظت می‌شود — فرم‌ها بدون توکن معتبر پذیرفته نمی‌شوند.
