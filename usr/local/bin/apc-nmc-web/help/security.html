Security and data-management areas: password changes, sessions, backup/restore and the API token. Account controls live on Users › User Access.

Changing Your Password

  • The Change Password card (Users › User Access) updates your own account only — even admins change their own password here (other accounts are managed on Users › User Access).
  • RADIUS-only users have no local credential — they see "managed by the authentication server".
  • Passwords are stored as PBKDF2 hashes in nmc.conf.

Active Sessions

Lists open sessions (user, IP, last activity). Administrators can Log off any session — e.g. a lost device — killing it instantly.

Backup / Restore

  • Download Backup: saves the current nmc.conf as a .bak file (admin only).
  • Restore: uploads a backup and replaces the config. A backup of the current file is taken automatically first. Invalid or oversized uploads are rejected.
  • Backups contain secrets (password hashes, tokens) — store the file safely.

API Token

The Update Settings card on About shows the Bearer token used for the REST API (/api/v1/…). Copy copies it to the clipboard, Generate creates a new one (invalidating the old), Clear disables the API. Visible to Administrator only — it grants full access.

Login Lockout

Repeated failed logins temporarily lock the source IP to slow brute force; failures are written to the Event Log.

Session Cookie

The nmc_session cookie is set with HttpOnly + Secure + SameSite=Lax, and every POST form carries a CSRF token — forged requests are rejected.
