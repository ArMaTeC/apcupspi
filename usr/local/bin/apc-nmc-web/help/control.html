Control › UPS Control sends real commands to the UPS via NUT (upsd).

Commands

CommandUPS behaviour
Reboot UPSCut and restore output — restarts attached equipment
Turn UPS OnRestore output power (load.on)
Turn UPS OffCut output; UPS waits for mains to return then restarts (shutdown.return)
Put UPS to SleepPower off after a delay; coordinates with server shutdown
Put UPS in BypassFeed the load directly from mains, bypassing the inverter
Mute / Alarm On / Alarm OffControl the UPS beeper

The two checkboxes modify the action: Signal PowerChute Network Shutdown Clients tells PCNS clients to shut their hosts down first, and Skip outlet off delays ignores the configured outlet shutdown delays.

Safety Rules

  • Power commands go through a confirmation page — the exact action is shown again before it runs.
  • These commands really cut UPS output; make sure attached servers are ready first.
  • Only Administrator and Device roles can send commands; Read-Only sees the page without controls.
  • Every command is written to the Event Log with the sending user.

Outlet Groups

On multi-outlet UPS models, Control › Outlet Groups shows each group separately: switch a group on/off, cycle it, and configure its own shutdown / reboot / power-on delays. Single-outlet units show one master group.

UPS vs. This Card

These commands act on the UPS, not the Raspberry Pi. Rebooting the card itself is done from Wireless Hardware (WiFi Setup) or via SSH.
