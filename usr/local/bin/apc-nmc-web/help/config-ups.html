Configuration › UPS manages UPS behaviour settings. Changes are stored in nmc.conf and applied immediately. Editable by Administrator and Device roles.

Identity

FieldPurpose
UPS NameLogical UPS name in NUT (default myups) — must match ups.conf
UPS IdentifierReported to clients as ups.id
LocationShown on the dashboard and in notifications
ContactResponsible person; included in notifications
Audible AlarmBeeper mode (on battery, at low battery, never) when the UPS supports it; otherwise a Mute Beeper button silences a currently sounding alarm

Behaviour Parameters

FieldPurpose
SensitivityHow readily the UPS transfers to battery on voltage fluctuation — higher means more transfers
Rated Output VoltageNominal output voltage the UPS regulates to
Low Battery Runtime (s)When remaining runtime drops below this, LB is raised
Low Battery Charge (%)Charge level that triggers the low-battery warning
Shutdown Delay (s)Grace period between the shutdown command and the actual output cut — lets servers power off cleanly
Restart Delay (s)Wait before output returns after mains is restored
Reboot Delay (s)How long output stays off during a reboot cycle
Transfer Voltage Low/HighInput voltage window; leaving it switches the UPS to battery

Battery

  • Battery Replaced: after a physical swap, press this to record today's date so battery age and the RB warning stay accurate.

Practical Notes

  • The ? badge beside each field explains it.
  • Cancel restores the saved values.
  • Leaving a page with unsaved form changes triggers the browser's unsaved-changes warning.
