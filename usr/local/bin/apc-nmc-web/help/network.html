About › Network

وضعیت شبکه کارت را نشان می‌دهد:

  • Interface / IP / MAC: آدرس‌های IPv4 هر اینترفیس (eth0، wlan0…) و آدرس فیزیکی.
  • Gateway / DNS: دروازه پیش‌فرض و سرورهای DNS فعلی.
  • Hostname: نام ماشین که در اعلان‌ها و SNMP sysName استفاده می‌شود.

برای تغییر IP/Hostname از ابزار سیستم (nmcli یا NetworkManager) استفاده کنید؛ این صفحه فقط‌خواندنی است.

About › Host

سلامت خود Raspberry Pi را مانیتور می‌کند:

  • CPU Temp: دمای SoC؛ بالای ~۸۰° باعث throttle و ریست‌های احتمالی می‌شود.
  • Load / Memory / Disk: بار سیستم، حافظه مصرفی و فضای آزاد کارت SD.
  • Uptime: مدت روشن بودن از آخرین ریست.
  • Services: وضعیت سرویس‌های اصلی (web, snmpd, modbus, dot1x, firewall, wifi-hw) — سبز=فعال.

About › UPS Variables

دامپ خام همه متغیرهای گزارش‌شده توسط NUT (ups.*, battery.*, input.*, output.*, device.*…) برای دیباگ و پشتیبانی. ستون Description توضیح هر متغیر را می‌دهد.

این جدول همان چیزی است که API و SNMP هم از آن استفاده می‌کنند؛ اگر متغیری اینجا نیست یعنی UPS آن را گزارش نمی‌کند.
