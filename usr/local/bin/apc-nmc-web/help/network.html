About › Network

Shows the card's network state:

  • Interface / IP / MAC: IPv4 address and hardware address of each interface (eth0, wlan0, …).
  • Gateway / DNS: default gateway and configured DNS servers.
  • Hostname: the machine name used in notifications and as SNMP sysName.

Changing IP or hostname is done at OS level (nmcli / NetworkManager) — this page is read-only.

About › Host

Monitors the health of the Raspberry Pi itself:

  • CPU Temp: SoC temperature — sustained ~80 °C means thermal throttling.
  • Load / Memory / Disk: system load, RAM use and free space on the SD card.
  • Uptime: time since the last reboot.
  • Services: state of the key services (web, snmpd, modbus, dot1x, firewall, wifi-hw) — green means active.

About › UPS Variables

Raw dump of every variable the UPS reports through NUT (ups.*, battery.*, input.*, output.*, device.*, …) with descriptions — useful for debugging and support. If a variable isn't listed, the UPS doesn't report it; the API and SNMP agent read this same table.
