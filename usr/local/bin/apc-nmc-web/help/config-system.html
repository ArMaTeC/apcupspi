صفحه Configuration › System بخش‌های مدیریتی سطح سیستم را یکجا دارد. برخی کارت‌ها فقط برای Administrator فعال‌اند و برای Read-Only به‌صورت خاکستری (disabled) دیده می‌شوند.

مدیریت کاربران

  • افزودن/ویرایش/حذف کاربران محلی (علاوه بر حساب پیش‌فرض apc).
  • برای هر کاربر یکی از چهار نقش Administrator، Device، Network یا Read-Only انتخاب می‌شود — جزئیات در نقش‌ها.
  • تنظیم Session Timeout مدت اعتبار نشست را مشخص می‌کند.

احراز هویت RADIUS

فیلدمعنی
Server / Portآدرس و پورت RADIUS (پیش‌فرض 1812)
Shared Secretراز مشترک با سرور RADIUS
Timeout / Retriesمهلت پاسخ و تعداد تلاش مجدد قبل از fallback به حساب محلی
Default Roleنقشی که به کاربران احرازشده از RADIUS داده می‌شود (مثلاً Read-Only)

وقتی RADIUS فعال است ابتدا RADIUS سؤال می‌شود و در صورت عدم پاسخ/رد، حساب محلی امتحان می‌شود.

سرویس‌ها

  • Modbus TCP: سرور Modbus برای BMSها — پورت (پیش‌فرض 502)، Unit ID و اجازه نوشتن (اجازه فرمان از طریق رجیستر). نقشه رجیسترها در docs/modbus-registers.md.
  • FTP Server: vsftpd chrooted برای انتقال فایل؛ فقط در صورت نیاز فعال کنید و پورت را در فایروال باز کنید.
  • MQTT Telemetry: انتشار دوره‌ای وضعیت UPS به بروکر MQTT — Host/Port، TLS، کاربر/رمز، Topic Prefix و Interval. با «Save & Test» پیام آزمایشی فرستاده می‌شود.

فایروال

قواعد nftables را از UI مدیریت می‌کند: پورت‌های مجاز TCP/UDP و محدودیت به آدرس‌های مشخص. قواعد پیش‌فرض فقط پورت‌های لازم (HTTP/S, SSH, NUT, SNMP…) را باز می‌گذارند. حین تغییر مراقب باشید پورتی که از آن وصل شده‌اید را نبندید.

Wired Port Authentication (802.1X)

احراز هویت پورت اترنت برای سوئیچ‌هایی با NAC (نه WiFi). متد EAP (PEAP/TTLS/TLS)، Identity، گذرواژه/گواهی و اینترفیس سیمی را تنظیم می‌کنید. در LAN معمولی غیرفعال بماند.

WiFi Setup

  • اتصال به شبکه: SSID و رمز — Scan لیست شبکه‌های اطراف را می‌آورد.
  • Wireless Hardware: فعال/غیرفعال کردن کامل WiFi و Bluetooth داخلی در سطح بوت (dtoverlay). هر تغییر نیاز به Reboot دارد؛ وضعیت «pending reboot» تا ریست نمایش داده می‌شود.

غیرفعال کردن رادیویی که از طریق آن به کارت وصل هستید، دسترسی را قطع می‌کند — قبل از Disable مطمئن شوید مسیر جایگزین دارید.

Secure Boot

وضعیت Secure Boot / چک‌های بوت را نشان می‌دهد (مستندات در docs/secure-boot.md).
