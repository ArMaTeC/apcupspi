Configuration › System groups the system-level management cards. Some are Administrator-only; Read-Only sees them greyed out.

User Management

  • Add/edit/delete local web users (in addition to the default apc account).
  • Each user gets one of four roles — Administrator, Device, Network or Read-Only. Details in Roles.
  • Session Timeout controls how long a login stays valid.

Network Services

  • Modbus TCP: serves UPS registers to BMS/SCADA clients — bind address, port (default 502), Unit ID, optional write access for UPS commands. Register map: docs/modbus-registers.md.
  • FTP Server: chrooted vsftpd for file transfer — enable only when needed and open the port in the firewall.
  • MQTT Telemetry: publishes UPS state JSON to <prefix>/state every Interval seconds — host, port, TLS, credentials. Save & Test sends a trial publish; the last publish result shows under the form.

Firewall

Manages nftables input rules: extra TCP/UDP ports to allow and optional source-CIDR restrictions. SSH/HTTP/HTTPS/NUT stay open. Be careful not to close the port you're connected through.

Wired Port Authentication (802.1X)

Ethernet port authentication for NAC-protected switches — not WiFi. Pick the wired interface, EAP method (PEAP/TTLS use a password; TLS uses client certs), identity and credentials. Leave disabled on a normal LAN.

WiFi Setup

  • Join a network: SSID + passphrase; Scan lists detected networks.
  • Wireless Hardware: fully enable/disable onboard WiFi and Bluetooth at boot level (dtoverlay). Changes need a reboot; the card shows "pending reboot" until then.

Disabling the radio you're connected through cuts access — confirm you have an alternative path (Ethernet) first.

Secure Boot

Shows secure-boot / boot-integrity status (background in docs/secure-boot.md).
